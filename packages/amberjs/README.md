# Amber

A JavaScript and TypeScript runtime built with **Rust** and **V8**.

- **Official Website:** [https://amberjs.com](https://amberjs.com)
- **GitHub Repository:** [https://github.com/zh30/amberjs](https://github.com/zh30/amberjs)

## Quick Install

```sh
# macOS / Linux
curl -fsSL https://amberjs.com/install.sh | sh
```

```powershell
# Windows PowerShell
irm https://amberjs.com/install.ps1 | iex
```
