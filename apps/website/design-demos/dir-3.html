一个二进制，跑 JavaScript 和 TypeScript。

给正在评估运行时的工程师。脚本、测试、本地服务和 Agent 工具从上面这条命令开始。每一项稳定能力都有书面契约，契约同时写明缺什么。

  • 装上macOS、Linux、Windows，或从源码构建。不要账号。卸掉就是删掉这个二进制。
  • 跑起来amber run，或进入 repl。测试写成 describe、test、expect。
  • 读契约依赖某个模块之前，打开它写明的边界。事实来源是 CURRENT_SCOPE。
  • 直接跑 TypeScript类型被擦掉，堆栈指回你的 .ts 行号。不做类型检查。
  • 测试不用另配框架amber test 会发现它们。watch 是整进程重跑，不是热替换。
  • 一个文件提供 HTTPamber serve 用 HTTP/1.1 跑一个 fetch 处理函数。加上 https 参数就用 rustls。
  • 默认什么都不许碰沙箱拒绝文件、网络、环境变量和子进程。放行要写明，并留下 JSONL 审计。
  • 工具清单是一份 JSONexport-tools 打印 schema 后退出。不执行工具，也不调用模型。
  • 记分卡是回归门禁2026-09-24，56 项全部通过。不是 Node 替代证明。

跑这个文件。

不做

  • 不是 Node每个模块只承诺契约里的子集。
  • 不做类型检查TypeScript 只擦除类型。
  • 不是 npmamber install 不是 npm、yarn 或 pnpm。
  • 不发性能数字没有提交、命令、硬件和正确性校验，就不发布。
  • parallel 会拒绝该参数以退出码 2 结束。
  • 不支持就失败明确不做的能力直接失败，不做桩。
