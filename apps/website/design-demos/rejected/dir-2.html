Amber

一个二进制，
跑 JavaScript 和 TypeScript。

给正在评估运行时的工程师。脚本、测试、本地服务和 Agent 工具，从下面这条安装命令开始。每一项稳定能力都有书面契约，契约同时写明缺什么。

v1.17.0。MIT 许可。记分卡是回归门禁，不是 Node 替代证明。

它替你做完的事

直接跑 TypeScript
类型被擦掉，堆栈指回你的 .ts 行号。不做类型检查。
测试不用另配框架
写成 describe、test、expect，amber test 会发现它们。watch 是整进程重跑，不是热替换。
一个文件就能对外提供 HTTP
amber serve 用 HTTP/1.1 跑一个 fetch 处理函数。加上 https 参数就用 rustls。它不是通用 Web 服务器。
默认什么都不许碰
沙箱拒绝文件、网络、环境变量和子进程。放行要写到具体路径或主机，并留下 JSONL 审计。
工具清单是一份 JSON
export-tools 打印 schema 后退出。它不执行工具文件，也不调用模型。

三步用起来

装上这个二进制
macOS、Linux 或 Windows。也可以从源码构建。
跑一个文件
amber run，或进入 repl。
再读契约
依赖某个模块之前，打开它写明的边界。

先把做不到的说完

不是 Node 的替代品
每个模块只承诺契约里的子集。
不做类型检查
TypeScript 只擦除类型。
不是 npm
amber install 安装 package.json 里的依赖。它不是 npm、yarn 或 pnpm。
不发性能结论
没有提交、命令、硬件和正确性校验的数字，不发布。
parallel 会拒绝
amber test 的 parallel 参数以退出码 2 结束。
