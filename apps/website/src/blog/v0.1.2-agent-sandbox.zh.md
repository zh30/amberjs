# Beejs v0.1.2 Agent 工具沙箱

Beejs v0.1.2 把运行时收成给 Agent Host 用的工具进程。模型仍走 OpenAI / Anthropic / llama.cpp；Beejs 只在默认拒绝的权限 broker 下执行 JS/TS 工具。

## 本版内容

- `bee run --sandbox` 先拒绝 fs/net/env/run，再叠加 `--allow-*` 或 `--permission-policy`。
- `--allow-read ./workspace` 是目录前缀 jail，不是精确路径。
- `--audit-log` 写 JSONL 决策（kind、action、resource、decision），不写 env 值或文件正文。
- `--export-tools` 从 `tools.json` 或导出函数打印 schema。
- `bee session` 是 stdin JSON-RPC（`tools/list`、`tools/call`）。`--isolate-per-call` 每次调用新建 isolate。
- `bee mcp` 是同一工具文件的 MCP stdio server。
- Node 符合性 24 条，含 Agent 拒绝路径。

## 示例

```bash
bee run --sandbox --permission-policy examples/agent/echo.policy.json --export-tools examples/agent/echo_tool.ts
bee session --sandbox --permission-policy examples/agent/echo.policy.json examples/agent/echo_tool.ts
```

稳定与预览边界见 [当前范围](/docs)。`feature=ai` 不是可服务的 LLM。
